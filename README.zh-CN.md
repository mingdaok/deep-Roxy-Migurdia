# DeepSeek Harness 洛琪希主题

一个为 DeepSeek Harness Web UI 制作的洛琪希风格视觉皮肤。

![效果图](docs/preview.png)

## 功能

- 异世界魔法学院暮色背景
- 洛琪希角色立绘与侧栏装饰
- 古金与冰蓝输入框边框
- 所有图片均打包在本地

## 安装

```bash
pnpm install
pnpm run check
dsh plugin --profile web add .
```

重启 Harness Web 服务并刷新页面。
