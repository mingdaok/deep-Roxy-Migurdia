# Roxy Migurdia Theme for DeepSeek Harness

A Roxy-inspired visual theme for the DeepSeek Harness Web UI.

![Preview](docs/preview.png)

## Features

- Isekai magic-academy dusk background
- Roxy character artwork and decorative sidebar
- Gold and ice-blue composer frame
- All artwork bundled locally

## Install

```bash
pnpm install
pnpm run check
dsh plugin --profile web add .
```

Restart the Harness web service and refresh the page.
